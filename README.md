# 七大营养素家常菜搭配（第一版）

一个单文件静态网页：`index.html`。不依赖任何框架和外部 CDN，所有数据都写在页面里，断网也能打开。

## 功能
- 营养素框架总览：七大营养素 → 作用 → 好买好做的食材 → 《中国居民膳食指南（2022）》每日参考量
- 同类食材互换表：蛋白质每份约7g，碳水每份约20g，脂类每份约10g，豆制品换算用指南原文
- 一餐搭配器：选主食、荤菜/蛋/豆、素菜、汤粥和用油方式，显示七大营养素覆盖了哪些、缺什么
- 今天吃了什么：17个食材开关，显示营养素覆盖数、蛋白质粗估、宝塔食物类别、建议补什么和推荐菜
- 菜谱库：42道家常菜，可按营养素和菜的类别筛选，附文字菜谱（HowToCook）和B站视频链接
- 单道菜做法：分步骤显示
- 数据来源与说明

## 使用
直接用浏览器打开 `index.html`，或者把它上传到任意静态托管（对象存储、GitHub Pages、Gitee Pages 等）。手机和微信内置浏览器都能正常显示，系统开了深色模式时会自动切换成暗色。

## 说明
- 现行指南是2022版；第六版正在修订，尚未发布（截至2026-11）。
- 除豆制品外，换算量和蛋白质克数都是按《中国食物成分表》常见值估算，只用来看大方向。
- 《你是你吃出来的》的相关说法来自读书笔记转述，没有逐字核对原书。
- 本页仅供家庭饮食参考，不构成医疗建议。
